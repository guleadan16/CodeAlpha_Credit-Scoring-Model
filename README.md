# 💳 Credit Scoring Model Using Machine Learning

## 📌 Project Overview
This project is a machine learning-based credit scoring system developed as part of the **CodeAlpha Machine Learning Internship**. The model predicts whether a loan applicant is a good or bad credit risk based on customer financial and personal information.

## 🎯 Objective
The objective of this project is to build a machine learning model that can evaluate a customer's creditworthiness and assist financial institutions in making better lending decisions.

## ✨ Features
- Data preprocessing and cleaning
- Feature scaling using StandardScaler
- Machine learning model training
- Credit risk prediction
- Save and load the trained model using Pickle

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Pickle

## 📂 Project Files
- `Credit_Scoring_Model.ipynb` – Model training notebook
- `german_credit_data.csv` *(or `german_credit_data(1).csv` if not renamed yet)* – Dataset
- `credit_scoring_model.pkl` – Trained model
- `scaler.pkl` *(or `scaler(1).pkl` if not renamed yet)* – Saved scaler

## 🚀 How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Run all cells to train the model.
5. Use the saved model to predict customer creditworthiness.

## 📊 Dataset
The project uses the German Credit dataset for predicting customer credit risk.
